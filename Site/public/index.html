Setup

From your Mac to your AI tools.

  1. Install and activate

    Get Apple Core from Gumroad, download it from your purchase receipt, and move it to Applications. Open the app and activate it with your license key. Requires macOS 15.1 or later.

  2. Choose what to share

    Open Apple Core’s Settings and enable the services you want to use, such as Calendar, Notes, Reminders, Contacts, Mail, or Messages. Grant the macOS permissions each service requests. For file access, explicitly select the folders you want to share.

    In the beta, choose Hosted by Apple Core and enter your invitation code, or choose Your own Cloudflare and complete sign-in.

  3. Connect your AI tool

    For hosted access, add this MCP server URL in a compatible AI client:

    https://mcp.applecore.app/mcp

    Choose OAuth when available. Enter the Connection ID from Apple Core, then its connection token on the Apple Core authorization page. Enable ongoing trust only for clients you want to recognize automatically.

    For your own Cloudflare connection, use the MCP address shown in the app. For a client on the same Mac, the default local address is http://127.0.0.1:8756/mcp. Keep your connection token private.

ChatGPT Work and Codex

In ChatGPT Work, open the plugin directory and choose Create app with developer mode enabled. Add the MCP URL, select OAuth, and connect. Custom MCP availability depends on your account and workspace settings.

For the Codex command line, add the hosted connection with:

codex mcp add apple-core --url https://mcp.applecore.app/mcp

Complete the browser authorization. Start with a read-only request, such as listing your calendars, to check the connection before asking for changes.

Claude.ai

Open Customize → Connectors, select +, then Add custom connector. Name it Apple Core and use https://mcp.applecore.app/mcp for hosted access. Add the connector, choose Connect, and complete Apple Core’s authorization in Safari or Chrome.

For Team or Enterprise accounts, an owner first adds the web connector under Organization settings → Connectors. Each member then connects individually. Enable Apple Core for your conversation and try a read-only request, such as listing calendars.

Claude.ai needs the public MCP address, not the local 127.0.0.1 address. Keep Apple Core running on the Mac whose services you want to use. See Claude’s custom connector guide for account-specific instructions.

Your Mac stays on. You stay in control.

Keep Apple Core running on an awake, connected Mac. Hosted requests pass through Cloudflare to your Mac; the AI provider receives the data returned by the tools you use.
