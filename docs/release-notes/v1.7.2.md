# Apple Core 1.7.2

This release fixes license-state errors, connection failures, and crashes caused
by invalid tool arguments.

- License removal and replacement now take effect immediately. Delayed Gumroad
  replies cannot restore a deactivated key or overwrite a newer activation.
- Gumroad verification rejects malformed replies and failed renewals. A failed
  disk write no longer restores access after a known revocation.
- Maps and Location reject invalid coordinates, spans, and search radii before
  calling Apple frameworks. Nearby searches use a supported default radius.
- Filesystem search and recent-file queries handle extreme numeric inputs
  without integer-overflow crashes.
- OAuth clients can use dynamic loopback ports consistently. Registering new
  clients no longer removes active connections or pending authorizations.
- Client metadata downloads and caches have enforced size limits.
- Cancelled or timed-out AppleScript and Shortcuts requests stop their child
  processes, including children that ignore the first termination request.

The regression suite now contains 190 tests. Existing licenses and configuration
remain compatible, and this update requires no new permissions.
