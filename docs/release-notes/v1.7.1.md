# Apple Core 1.7.1

One change: activation with the license key from your Gumroad purchase.

## Paste the key, not a file

1.7.0 required a signed license file. From 1.7.1, **Settings → License** accepts the license key Gumroad shows on the purchase page and in the receipt. Apple Core checks the key with Gumroad when you activate it and about once a day afterwards. Only the key and the product ID are sent. A Mac that is offline keeps its license for 14 days, so a network outage never switches a licensed server off. A refunded or disabled key closes the gate at the next check.

A signed license file still works exactly as before, verified offline.

Updates download from `assets.amesvt.com`. Nothing to redo, and no new permissions.
