# Apple Core 2.0 Beta 1

Adds an invitation-based hosted connection at `mcp.applecore.app/mcp`, alongside
the existing option to use your own Cloudflare account and domain. Hosted
customers do not need Cloudflare credentials or a tunnel helper. Onboarding
explains both choices and the requirement to keep the Mac running.

Each Mac has a separate relay identity. Apple Core continues to verify OAuth
PKCE, approve clients, authenticate tools, and enforce enabled-service and
filesystem access on the Mac. The shared endpoint serves the Apple Core icon.

There is no new hosted payment check in this beta. Existing app activation is
unchanged. Beta updates are installed manually, separately from the stable
Sparkle feed and Gumroad download.

Hosted access currently supports Streamable HTTP POST and DELETE, up to four
concurrent requests, 1 MiB requests, and 8 MiB responses. Large captures and
standalone SSE subscriptions are not supported by this beta relay. Switching
from a self-hosted address requires reconnecting OAuth clients.

Release acceptance remains pending home-server installation and the actual
ChatGPT Work/Codex read-only checks. See `Hosted/README.md` for operator details.
